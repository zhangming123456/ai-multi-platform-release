## 提交信息格式

```
<type>: <subject>
```

### type 类型

- `feat` 新功能
- `fix` 修复 Bug
- `refactor` 代码重构
- `perf` 性能优化
- `style` 代码格式（不影响功能）
- `docs` 文档更新
- `test` 测试相关
- `chore` 构建/依赖/工具链
- `ci` CI/CD 配置

### 必要条件

- **必须使用中文**，禁止英文提交信息
- subject 简明扼要，不超过 50 个字符
- 以动词开头描述本次改动做了什么
