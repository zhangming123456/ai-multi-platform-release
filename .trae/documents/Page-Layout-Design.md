# 页面布局设计

## 1. 整体布局架构

### 1.1 布局组合方式

采用经典的 **固定侧边栏 + 顶部头部 + 主内容区** 三栏式布局，由 `AppLayout.vue` 统一编排：

```
┌─────────────────────────────────────────────────────────┐
│  App.vue (仅 <router-view/>)                             │
│  └─ AppLayout.vue                                        │
│     ├─ 背景装饰层（三层彩色模糊光晕，-z-10）             │
│     ├─ 遮罩层（移动端侧边栏抽屉打开时）                  │
│     ├─ flex 容器                                         │
│     │  ├─ <aside> 侧边栏（fixed 定位）                   │
│     │  │   └─ AppSidebar                                 │
│     │  └─ <div> 主区域（flex-1 + flex-col）              │
│     │      ├─ AppHeader（sticky top-0 z-20）             │
│     │      └─ <main> 主内容区（max-w-[1400px] mx-auto）  │
│     │          └─ <router-view />                        │
└─────────────────────────────────────────────────────────┘
```

### 1.2 布局状态

| 状态                  | 类型           | 说明                   |
| --------------------- | -------------- | ---------------------- |
| `isSidebarCollapsed`  | `Ref<boolean>` | 桌面端侧边栏折叠状态   |
| `isMobileSidebarOpen` | `Ref<boolean>` | 移动端抽屉式侧边栏开关 |
| `isMobile`            | `Ref<boolean>` | 屏幕宽度 < 768px 判定  |

### 1.3 尺寸规范

| 元素             | 展开                                        | 折叠                    |
| ---------------- | ------------------------------------------- | ----------------------- |
| 侧边栏宽度       | `248px`                                     | `64px`                  |
| 头部高度         | `56px`                                      | `56px`（极小屏 `44px`） |
| 主内容区最大宽度 | `1400px`                                    | —                       |
| 主内容区 padding | `px-4 md:px-6 lg:px-8 py-4 md:py-6 lg:py-7` | 极小屏 `8px 10px`       |

### 1.4 组件通信

| 组件         | Props                    | Emits                           |
| ------------ | ------------------------ | ------------------------------- |
| `AppSidebar` | `{ collapsed: boolean }` | `toggle: []`、`closeMobile: []` |
| `AppHeader`  | `{ collapsed: boolean }` | `toggleSidebar: []`             |

## 2. 侧边栏设计（AppSidebar）

### 2.1 菜单分组配置

| 分组 key  | 名称       | 图标  | order | wrapGroup            |
| --------- | ---------- | ----- | ----- | -------------------- |
| top       | （无名称） | —     | 0     | false（顶级平铺）    |
| content   | 内容管理   | file  | 1     | true（折叠为子菜单） |
| review    | 审核管理   | check | 2     | true                 |
| platforms | 平台管理   | apps  | 3     | false                |
| rbac      | 权限管理   | safe  | 4     | true                 |
| system    | 系统管理   | tool  | 5     | true                 |

### 2.2 图标注册表

支持 12 个图标别名，来源于 `@arco-design/web-vue/es/icon`：

`home / file / send / apps / settings / code / safe / storage / tool / check / user / edit`

默认回退到 `IconFile`。

### 2.3 菜单生成逻辑

1. 通过 `router.getRoutes()` 过滤出含 `meta.sidebarType` 与 `meta.title` 的路由
2. 按 `meta.sidebarType` 分组，组内按 `meta.sidebarOrder` 排序
3. 通过 `permStore.hasPermission(permKey, ctx)` 做权限过滤
4. `wrapGroup=true` 的分组包成 `a-sub-menu`；否则平铺到顶级
5. 选中态 `selectedKey`：基于当前 `route.path` 前缀匹配
6. `openKeys` 通过 `watch(route.path)` 自动同步打开当前路由所在分组

### 2.4 底部用户卡片

- 仅在 `!collapsed` 时显示
- 头像 `a-avatar`（36px），无图时使用绿色→蓝色渐变背景 + 昵称首字母
- 显示 `nickname` 与 `username`
- hover 时显示红色退出图标 `IconExport`
- 点击跳转 `/profile`

### 2.5 Logo 区域

- 蓝色渐变圆角方块（`linear-gradient(135deg, #007aff 0%, #0055d4 100%)`）含 "M" 字母
- 阴影：`0 4px 14px rgba(0,122,255,0.35), 0 1px 3px rgba(0,122,255,0.2)`
- 旁边显示 "Matrix" / "Studio" 双行文字
- 折叠时隐藏文字

## 3. 头部设计（AppHeader）

固定高度 `56px`，`sticky top-0 z-20`，毛玻璃背景 `bg-white/60 backdrop-blur-xl`。

### 3.1 左侧区域

| 元素     | 说明                                                                            | 响应式        |
| -------- | ------------------------------------------------------------------------------- | ------------- |
| 汉堡按钮 | `a-button type="text"`，根据 `collapsed` 切换 `IconMenuUnfold` / `IconMenuFold` | 全屏显示      |
| 面包屑   | `a-breadcrumb`，结构：`Matrix`（首页）+ 当前路径名称                            | `sm` 以上显示 |

面包屑内置 14 条路径映射（`/`→仪表盘、`/profile`→个人资料、`/rbac/users`→用户设置 等），未命中时回退为 "页面"。

### 3.2 右侧区域

| 元素               | 说明                                        | 响应式        |
| ------------------ | ------------------------------------------- | ------------- |
| `RegionSwitcher`   | 区域切换器                                  | 全屏显示      |
| 搜索框             | `a-input-search`，宽度 224px，`allow-clear` | `md` 以上显示 |
| `NotificationBell` | 通知铃铛组件                                | 全屏显示      |

## 4. 响应式设计

### 4.1 断点规范

| 断点   | 阈值           | 行为                                |
| ------ | -------------- | ----------------------------------- |
| 极小屏 | `< 248px`      | 深度压缩 padding/字号，特殊样式覆盖 |
| 移动端 | `< 768px (md)` | 侧边栏转抽屉模式，隐藏搜索框        |
| 小屏   | `< 640px (sm)` | 隐藏面包屑                          |
| 桌面端 | `≥ 768px`      | 显示搜索框，侧边栏固定              |

### 4.2 移动端侧边栏抽屉模式

- 侧边栏：`fixed inset-y-0 left-0` + `-translate-x-full`（关闭）/ `translate-x-0`（打开）
- 遮罩层：`fixed inset-0 bg-black/20 backdrop-blur-sm z-30 md:hidden animate-fade-in`
- 主区域 `marginLeft` 为 `0`（不预留侧边栏空间）
- 点击菜单项后自动关闭抽屉

### 4.3 极小屏适配（< 248px）

- `main` padding 强制缩小至 `8px 10px`
- `header` 高度缩至 `44px`，padding 收紧
- `arco-menu-item` 高度 32px，字号 12px

## 5. 视觉设计规范

### 5.1 配色系统

采用 Apple/iOS 风格调色板（CSS 内联，未提取为变量）：

| 用途         | 颜色                    | 说明       |
| ------------ | ----------------------- | ---------- |
| 主背景       | `#F5F5F7`               | Apple 灰   |
| 主色         | `#007AFF`               | Apple Blue |
| 主色渐变     | `#007AFF → #0055D4`     | 135deg     |
| 紫色辅助     | `#5856D6`               | —          |
| 青色辅助     | `#5AC8FA`               | —          |
| 绿色（成功） | `#30D158` / `#34C759`   | —          |
| 橙色（警告） | `#FF9500`               | —          |
| 红色（危险） | `#FF3B30`               | —          |
| 主文本       | `#1D1D1F`               | —          |
| 次要文本     | `#86868B`               | —          |
| 边框         | `rgba(0,0,0,0.04~0.05)` | —          |

### 5.2 毛玻璃效果（Frosted Glass）

| 应用位置       | 样式                                                                    |
| -------------- | ----------------------------------------------------------------------- |
| 侧边栏容器     | `bg-white/80 backdrop-blur-xl`                                          |
| 头部           | `bg-white/60 backdrop-blur-xl`                                          |
| 移动端遮罩     | `bg-black/20 backdrop-blur-sm`                                          |
| 登录卡片       | `backdrop-filter: blur(40px) saturate(180%)` + `rgba(255,255,255,0.72)` |
| RBAC 卡片      | `bg-white/80 backdrop-blur-xl rounded-2xl`                              |
| 数据库提示浮层 | `rgba(255,255,255,0.96) backdrop-filter: blur(20px) saturate(180%)`     |
| TokenPlan 弹窗 | `backdrop-filter: blur(28px) saturate(180%)` + `rgba(255,255,255,0.96)` |

### 5.3 背景装饰（三层光晕）

固定定位 `-z-10 pointer-events-none`，使用 `radial-gradient` + `blur-[120px]`：

| 位置 | 颜色      | 尺寸      | 透明度 |
| ---- | --------- | --------- | ------ |
| 右上 | `#007AFF` | 700×700px | 0.12   |
| 左中 | `#5856D6` | 560×560px | 0.08   |
| 右下 | `#5AC8FA` | 480×480px | 0.06   |

### 5.4 圆角与阴影

- 卡片圆角：`rounded-[10px]`、`rounded-[12px]`、`rounded-2xl`（16px）、`rounded-[20px]`
- Logo 方块阴影：`0 4px 14px rgba(0,122,255,0.35), 0 1px 3px rgba(0,122,255,0.2)`
- 卡片阴影：`0 2px 12px rgba(0,0,0,0.04)`（软阴影）

### 5.5 过渡动画

| 元素                 | 过渡                                                                     |
| -------------------- | ------------------------------------------------------------------------ |
| 侧边栏宽度切换       | `transition-all duration-350 ease-out`                                   |
| 主区域位移           | `transition-all duration-350 ease-out`                                   |
| 用户卡片 hover       | `transition-all duration-250`                                            |
| 移动端遮罩           | `animate-fade-in`                                                        |
| 角色卡片 hover       | `transform: translateY(-2px)` + `cubic-bezier(0.25, 0.1, 0.25, 1) 0.22s` |
| 约束卡片 hover       | 同上                                                                     |
| TokenPlan 卡片 hover | `transform: translateY(-2px)` + 阴影                                     |
| 模板卡片入场         | `animationDelay: index * 50ms`                                           |
| StatCard 入场        | `animationDelay: index * 70ms`                                           |

> **注**：路由切换未配置 `<transition>` 过渡动画。

### 5.6 字体规范

- 字距微调：`tracking-[-0.01em]`、`tracking-tight`
- 紧凑行高：`leading-tight`
- 等宽字体：`SF Mono`（SQL、表名、列名、日志终端）
- 等宽数字：`tabular-nums`（时间列）

## 6. 通用组件规范

### 6.1 PageHeader 组件

除 `Review.vue` 和 `Forbidden.vue` 外，所有页面统一使用 `PageHeader` 组件作为顶部标题栏，包含：

- 页面标题（h2）
- 副标题描述（灰色小字）
- 右侧操作区（按钮/标签）

### 6.2 SegmentedControl 分段控件

用于列表页的平台/状态筛选，支持：

- 全部 / 公众号 / 小红书 / 抖音 / 视频号（平台筛选）
- 全部 / 待发布 / 发布中 / 已完成 / 失败（状态筛选）

### 6.3 StatCard 统计卡片

用于仪表盘，4 列布局：

- `a-row :gutter="[16, 16]"`
- `:xs="24" :md="12" :lg="6"`
- 入场延迟动画 `delay: index * 70`

### 6.4 StatusBadge 状态徽章

用于列表中的状态展示，支持多色（成功/失败/进行中等）。

### 6.5 PlatformIcon 平台图标

用于平台标识展示，支持微信公众号、小红书、抖音、视频号。

## 7. 页面布局详解

### 7.1 登录页 `/login`

**布局结构**：全屏居中毛玻璃卡片

```
┌──────────────────────────────────────┐
│  全屏背景（三层光球模糊）              │
│  ┌────────────────────────────┐      │
│  │  毛玻璃登录卡片（400px）    │      │
│  │  ├─ Logo（4色方块 SVG）     │      │
│  │  ├─ Matrix 标题             │      │
│  │  ├─ 副标题                  │      │
│  │  ├─ 用户名输入              │      │
│  │  ├─ 密码输入                │      │
│  │  └─ 登录按钮（44px 高）     │      │
│  └────────────────────────────┘      │
└──────────────────────────────────────┘
```

- 卡片：`backdrop-filter: blur(40px) saturate(180%)` + `rgba(255,255,255,0.72)` + `border-radius: 24px`
- 三色光球：蓝 `#007aff` / 紫 `#5856d6` / 青 `#5ac8fa`，`blur(120px)`
- 响应式：`max-width: calc(100vw - 32px)`，248px 断点全屏适配

### 7.2 仪表盘 `/`

**布局结构**：统计卡片 + 双列内容区

```
┌────────────────────────────────────────┐
│  PageHeader（含平台运行状态 tag）        │
├────────────────────────────────────────┤
│  ┌──────┬──────┬──────┬──────┐         │
│  │账号数│今日  │待处理│AI生成│  4 列   │
│  └──────┴──────┴──────┴──────┘         │
├────────────────────────────────────────┤
│  ┌────────────┬──────────────┐         │
│  │ 账号健康度  │  最近发布     │         │
│  │ (进度条列表)│  (a-list)    │         │
│  └────────────┴──────────────┘         │
└────────────────────────────────────────┘
```

- 统计卡片：`a-row :gutter="[16, 16]"`，`:xs="24" :md="12" :lg="6"`
- 双列内容：`a-row :gutter="[24, 16]"`，左 `:xs="24" :lg="10"`，右 `:xs="24" :lg="14"`
- 特殊效果：平台运行指示点 `pulse` 脉冲动画（2s infinite），进度条颜色随健康度切换

### 7.3 平台管理 `/platforms`

**布局结构**：分段筛选 + 卡片网格

```
├────────────────────────────────────────┤
```

**布局结构**：筛选条 + 数据表格


**布局结构**：预览区 + 双列（日志终端 + 输入表单）

```
└────────────────────────────────────────┘
```

- 日志终端：深色背景 `#1d1d1f` + 径向渐变高光 + 三色圆点（红黄绿）
- 流式光标动画 `cursor-blink`（0.9s 闪烁）
- 日志按等级着色（info 灰 / req 橙 / ok 绿 / err 红）
- 平台 checkbox：`a-row :gutter="[8, 8]"`，`:span="12"`

## 8. 布局规范总结

### 8.1 布局模式分类

| 模式                    | 适用页面                              | 说明                                                     |
| ----------------------- | ------------------------------------- | -------------------------------------------------------- |
| 全屏居中                | 登录页、403                           | `min-height: 100vh` + `flex items-center justify-center` |
| 统计卡片 + 双列         | 仪表盘                                | `a-row` + `a-col` 栅格                                   |
| 分段筛选 + 卡片网格     | 平台管理、模板管理                    | `SegmentedControl` + `a-row` 卡片网格                    |
| 分段筛选 + 表格         | 发布管理                              | `SegmentedControl` + `a-table`                           |
| 筛选条 + 表格           | 内容列表、SQL 审核、用户注册审核      | `a-space` 筛选 + `a-table`                               |
| 双列（侧栏 + 主区）     | 数据库控制台                          | 固定宽度侧栏 + flex-1 主区                               |
| 双列（左角色 + 右权限） | 权限管理                              | `lg:w-[200px]` + `flex-1`                                |
| 双列（方案 + 总览）     | Token 方案                            | `a-row :lg="16"` + `:lg="8"`                             |
| 双视图 + 侧栏           | 角色管理                              | 卡片/表格切换 + 继承侧栏                                 |
| 单卡片表单              | 创建/编辑用户、修改密码、编辑权限字典 | `a-card` + `a-form vertical` + `max-w-[480px~560px]`     |
| 多模块卡片              | 自定义权限、权限字典管理              | 毛玻璃卡片网格堆叠                                       |
| 卡片网格                | 约束管理                              | `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3`         |
| 窄列卡片堆叠            | 个人中心                              | `max-width: 680px`                                       |
| 第三方嵌入              | API 文档                              | Swagger UI 容器                                          |

### 8.2 响应式策略

| 策略          | 说明                                                                      |
| ------------- | ------------------------------------------------------------------------- |
| Arco 栅格     | `a-row :gutter="[16, 16]"` + `:xs="24" :md="12" :lg="6"`                  |
| Tailwind Grid | `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`                    |
| Tailwind Flex | `flex flex-col lg:flex-row gap-5`                                         |
| 媒体查询      | `@media (max-width: 900px)` / `(max-width: 480px)` / `(max-width: 248px)` |
| 显示/隐藏     | `hidden md:block`（搜索框）、`hidden sm:block`（面包屑）                  |

### 8.3 通用设计原则

1. **卡片无边框**：统一 `:bordered="false"`，依赖阴影与圆角
2. **毛玻璃优先**：RBAC 系列页面、登录页、弹窗普遍使用 `backdrop-blur`
3. **悬浮反馈**：可交互卡片统一 `translateY(-2px)` + 阴影加深
4. **入场动画**：列表卡片使用 `animationDelay: index * Nms` 错位入场
5. **等宽字体**：SQL、日志、时间数字使用 `SF Mono` 或 `tabular-nums`
6. **颜色语义**：成功绿、警告橙、危险红、主色蓝，严格遵循 Apple 调色板
7. **248px 断点**：所有页面支持极小屏深度压缩
