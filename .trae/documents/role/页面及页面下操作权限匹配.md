# 页面及页面下操作权限匹配

## 权限判断表达式说明

| 符号 | 含义                    |
| ---- | ----------------------- |
| `    |                         | `   | 或（OR），满足任一条件即可 |
| `&`  | 且（AND），必须全部满足 |
| `()` | 分组，控制优先级        |

## 内置判断函数

> 完整函数定义及使用规范见 [权限表达式内置判断函数](权限表达式内置判断函数.md)。

| 函数              | 参数形式                                        | 含义                                            |
| ----------------- | ----------------------------------------------- | ----------------------------------------------- |
| `isAuthenticated` | `isAuthenticated()`                             | 当前用户已登录（JWT 校验通过）                  |
| `isSuperAdmin`    | `isSuperAdmin()` 或 `isSuperAdmin(user_id)`     | 当前/目标用户为超级管理员（role=admin，ID="1"） |
| `isAdmin`         | `isAdmin()` 或 `isAdmin(user_id)`               | 当前/目标用户为管理员（role=admin 或 manager）  |
| `isSelf`          | `isSelf()` 或 `isSelf(user_id)`                 | 目标用户为当前登录用户自身                      |
| `isBuiltInAdmin`  | `isBuiltInAdmin()` 或 `isBuiltInAdmin(user_id)` | 目标用户为内置超级管理员（ID="1"）              |
| `isAdminType`     | `isAdminType(role_type)`                        | 角色 role_type 为 "admin"                       |
| `isOtherType`     | `isOtherType(role_type)`                        | 角色 role_type 为 "other"                       |

## 三、页面内操作权限（按钮级）

### 3.1 用户管理页 `/rbac/users`

| 操作                   | 权限判断表达式                                                     |
| ---------------------- | ------------------------------------------------------------------ |
| 创建用户按钮           | `users:create:write`                                               |
| 编辑用户按钮（每行）   | `users:update:read \|\| isSelf(user_id)`                           |
| 修改密码按钮（每行）   | `users:change_password:write \|\| isSelf(user_id)`                 |
| 删除用户按钮（每行）   | `users:delete:write & !isBuiltInAdmin(user_id) & !isSelf(user_id)` |
| 自定义权限按钮（每行） | `users:custom_permissions:read \|\| isSelf(user_id)`               |

### 3.2 创建用户页 `/rbac/users/create`

| 操作                  | 权限判断表达式       |
| --------------------- | -------------------- |
| 管理员/审核员角色选项 | `users:create:write` |
| RBAC3 角色分配选择器  | `users:create:write` |

### 3.3 编辑用户页 `/rbac/users/:id/edit`

| 操作           | 权限判断表达式                            |
| -------------- | ----------------------------------------- |
| 角色分配可见性 | `users:update:write & isAdmin()`          |
| 表单提交按钮   | `users:update:write \|\| isSelf(user_id)` |

### 3.4 修改密码页 `/rbac/users/:id/password`

| 操作                   | 权限判断表达式                                   |
| ---------------------- | ------------------------------------------------ |
| 管理员修改他人密码表单 | `users:change_password:write & !isSelf(user_id)` |
| 用户自身修改密码       | `isSelf(user_id)`                                |

### 3.5 自定义权限页 `/rbac/users/:id/permissions`

| 操作                             | 权限判断表达式                                       |
| -------------------------------- | ---------------------------------------------------- |
| 保存权限按钮                     | `users:custom_permissions:write` |
| 权限编辑开关（切换）             | `users:custom_permissions:write` |
| 只读模式提示                     | `!users:custom_permissions:write`                    |
| 管理类型权限过滤（非管理员角色） | `isOtherType(role_type)` 时隐藏管理类型权限          |
| 管理类型权限显示                 | `isAdminType(role_type)` 时显示全部权限              |
| 可编辑权限范围                   | 限定在目标用户角色权限闭合范围内，不可超出角色授予的权限 |

### 3.6 权限管理页 `/rbac/permissions`

| 操作                             | 权限判断表达式                              |
| -------------------------------- | ------------------------------------------- |
| 添加权限按钮                     | `roles:manage:write`                        |
| 保存权限按钮                     | `roles:manage:write`                        |
| 管理类型权限过滤（非管理员角色） | `isOtherType(role_type)` 时隐藏管理类型权限 |
| 管理类型权限显示                 | `isAdminType(role_type)` 时显示全部权限     |

### 3.7 权限字典管理页 `/rbac/permissions/enum`

| 操作              | 权限判断表达式                                               |
| ----------------- | ------------------------------------------------------------ |
| 编辑资源名称/描述 | `permissions:manage:write`                                   |
| 所有权限枚举可见  | `permissions:read`（管理类型角色权限，所有权限均可在此修改） |

### 3.8 约束管理页 `/rbac/constraints`

| 操作          | 权限判断表达式             |
| ------------- | -------------------------- |
| 创建约束按钮  | `constraints:manage:write` |
| 编辑约束按钮  | `constraints:manage:write` |
| 删除约束按钮  | `constraints:manage:write` |
| 启用/禁用开关 | `constraints:manage:write` |

## 四、角色类型权限过滤规则

### 4.1 管理类型权限（仅 admin 类型角色可配置）

以下资源前缀的权限仅对 `role_type = "admin"` 的角色可见/可编辑：

| 资源前缀      | 说明                    |
| ------------- | ----------------------- |
| `db`          | 数据库控制台 + SQL执行  |
| `db_history`  | SQL执行历史             |
| `api_docs`    | API文档                 |
| `permissions` | 权限管理 + 权限字典维护 |
| `roles`       | 角色管理 + 角色维护     |
| `constraints` | 约束管理 + 约束维护     |

### 4.2 过滤规则

- **权限管理页**：非管理员角色仅显示和编辑非管理类型权限
- **自定义权限页**：若目标用户所有角色均为 `role_type = "other"`，仅显示和编辑非管理类型权限
- **权限字典管理页**：所有权限均可查看和编辑（管理类型角色专用页面）
