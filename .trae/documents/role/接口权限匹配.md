# 接口权限匹配

## 权限判断表达式说明

| 符号 | 含义 |
|------|------|
| `\|\|` | 或（OR），满足任一条件即可 |
| `&` | 且（AND），必须全部满足 |
| `!` | 非（NOT），对后面的条件取反 |
| `()` | 分组，控制优先级 |

## 内置判断函数

| 函数 | 参数 | 含义 |
|------|------|------|
| `isSuperAdmin` | 无（作用于当前用户） | 当前用户为超级管理员（role=admin，ID="1"） |
| `isAdmin` | 无（作用于当前用户） | 当前用户为管理员（role=admin 或 manager） |
| `isSelf` | 无 → 比对 `ctx.user_id`；`isSelf(user_id)` → 比对指定 ID | 目标用户为当前登录用户自身 |
| `isBuiltInAdmin` | 无 → 比对 `ctx.user_id`；`isBuiltInAdmin(user_id)` → 比对指定 ID | 目标用户为内置超级管理员（ID="1"） |

> **上下文传递**：无参函数默认作用于当前登录用户；带参函数强制匹配指定用户 ID。
> - `permStore.hasPermission('users:delete:write&!isBuiltInAdmin&!isSelf')` — 比对当前用户
> - `permStore.hasPermission('users:delete:write&!isBuiltInAdmin(user_id)&!isSelf(user_id)', { user_id: 'xxx' })` — 比对指定用户

## 十四、用户管理模块 `/api/v2/users`

| HTTP | 路径 | 描述 | 权限判断表达式 |
|------|------|------|----------------|
| GET | `/api/v2/users` | 获取用户列表（非管理员仅看同角色用户） | `users:read&(isAdmin\|\|isSelf\|\|hasSameRole(当前用户, 目标用户))` |

| PUT | `/api/v2/users/{user_id}` | 更新用户信息（昵称、邮箱、角色分配等） | `users:update:write&(isAdmin\|\|isSelf(user_id)\|\|hasSameRole(当前用户, 目标用户))` |

## 权限判断函数实现说明

| 函数 | 实现逻辑 |
|------|----------|
| `isAuthenticated` | JWT Token 校验通过 → `True` |
| `isSuperAdmin` | `user.role == "admin"` 且 `user.id == "1"` |
| `isAdmin` | `user.role in ["admin", "manager"]` |
| `isSelf` | 无参：`current_user.id == ctx.user_id`；有参：`current_user.id == args[0]` |
| `isBuiltInAdmin` | 无参：`ctx.user_id == "1"`；有参：`args[0] == "1"` |
| `isOwnContent` | `content.user_id == current_user.id` |
| `isOwnAccount` | `account.user_id == current_user.id` |
| `hasSameRole` | 当前用户与目标用户的 RBAC 角色名称集合有交集 |
